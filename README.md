## 🛠️ Getting Started Locally

```bash
# 1. Clone repository
git clone https://github.com/yugeshpandey22/por.git

# 2. Navigate to project directory
cd por

# 3. Install dependencies
npm install

# 4. Start development server
npm run dev

# 5. Production build
npm run build
```
